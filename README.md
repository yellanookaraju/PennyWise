# PennyWise – Smart Expense Tracker

## Project Overview

PennyWise is a personal expense tracking Android application that I am developing as part of the Mobile App Development module at Teesside University.

The main aim of this application is to help users manage their income, expenses and monthly budgets in one place. It will also provide spending insights to help users understand their spending habits.

## Technologies

- Kotlin
- Android Studio
- Jetpack Compose
- Git and GitHub
